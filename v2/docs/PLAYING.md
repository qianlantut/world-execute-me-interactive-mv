# 2.0 操作与演出

交互随歌曲段落出现、结束后自动收起。无需完成操作才能继续；没有分支剧情，不操作时也有自动演出。

| 段落 | 可以做什么 |
| --- | --- |
| 开场 | 拖动插头接通电源、拼合框线、点击填入 data、推动世界加载 |
| 数据显现 | 按节奏命中音符，看角色从数据块逐步显现 |
| 几何与电流 | 操作点、圆周与波形；切换 AC / DC |
| 时间与深度 | 滚动年份，拖动影响空间的旋转和下潜 |
| 果实与生命 | 划过果实触发切开与文字反馈，触碰其他歌词对象 |
| 形象与昼夜 | 切换 F/M、S/M 形象，操作昼夜刻度 |
| 振动 | 左右拖动篮子接住下落的波动 |
| 离开与碎片 | 点击进度条、擦掉错误信息，过程仍由音乐推进 |
| 后半段 | 参与三位 AI 对应的节奏演出，在倒数时选择 GPT、触发碎屏 |
| 碎屏之后 | 在新的场景中继续音游，最后进入收束与署名 |

三段音游分别累计 COMBO 与 FULL COMBO；空点和漏拍不会暂停音乐。末段三选一保持单一结局，未选择时也会自动继续。

| 控制 | 作用 |
| --- | --- |
| 空格 | 暂停 / 播放 |
| 左右方向键 | 前后跳转五秒 |
| F | 全屏 |
| H | 显示 / 隐藏播放界面 |
| 章节与进度条 | 跳到指定段落 |
| 中文 / EN | 切换歌词语言 |
| 画质 | 设备负载较高时降低画质 |

播放器不会要求 API Key，不会调用在线大模型。全部演出在浏览器里运行。
