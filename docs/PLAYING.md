# 演出与操作

## 歌词与操作

已接入用户提供的完整英文 LRC（110 个时间点、101 条非空歌词），默认显示对应的中文意译。控制栏「中文 / EN」可切换原文；「替换歌词」可读取本地 LRC，文件仅在浏览器内处理。原始 LRC 保持原时间戳；播放器按音频统一提前 0.25 秒校准。中文是字幕意译，保留数学、程序与情感双关，并非中文翻唱。

歌词对象可以直接操作，触摸屏也支持。每项操作只属于当前对象；歌词切换、对象隐藏或回拖进度时，其操作、物体和拖动捕获都会清空。S/M 的角色姿态按用户选择保留到「可你最终离开了」，开关本身仍随歌词退场。

| 接通电源、创造对象 | 拖动插头接通电路；拖动碎片只会累加装配进度，不会因过量或反向拖动而散开 |
| 填入参数 | 点击机器吐出 data；小块受重力下落、碰撞、堆积，短暂的时间窗内无法装满容器 |

| 维度、圆周、切线、边界 | 拖动点阵旋转视角，将圆周铺开为等长直线，移动切点或限制边界；无人操作时边界逐渐收拢，并在 LIMITATIONS 落点进一步压缩无穷曲线，拖动可接管 |

空格暂停 / 播放；左右方向键跳转 5 秒；F 全屏；H 隐藏播放界面。「章节」和进度条可直接跳转。手机使用拖动、划切和点击。桌面鼠标会随当前对象变成方向箭头、旋转轨道、滚轮、橡皮擦、刀刃、印章或点击手势；进入可操作区域会变亮，按下时有反馈，播放控制栏保留普通鼠标。

切水果不增加音效。开场右侧从碎框拼成方框，data 填入并与百分比同步；START 后数据重排成人物剪影。15 秒至「我若是一簇点」前，左侧歌词对象退场并加入音游。第一枚音符从画面外飞行约 2 秒，17 秒才到达判定线；每个音符经过后，剪影的一部分自动恢复为彩色人物，直到完整显现，不点击也会完成还原。

## 倒数、碎屏与后景

前两次选择已删除。DeepSeek 与 Claude 的人物出场移至 2:16 后的间奏；2:28 起出现被马赛克、遮眼条和错位切片损坏的 GPT。

开场纯音乐段、2:15 至三选一前，以及碎屏后的后半段，均有可选音游：音符落到移动、旋转的判定线上时点击。命中标志跟随当前出场角色：鲸鱼娘阶段是 DeepSeek，Claude 阶段是 Claude，其余为 GPT；不会轮流交换。命中时大尺寸标志与亮线展开，漏拍也会继续完整演出。三段独立显示 COMBO；漏拍断连，全部音符真实命中才显示 FULL COMBO，跳过或不操作不会获得全连。「我学会了怎样去爱」至「困在爱里」（约 02:57.17–03:13.31）延续 EXECUTION 的每拍一枚音符密度，连续使用同一拍网格。最后一段音游在 03:27 收束，此后只保留结尾画面。

约 **2:38.78–2:41.55** 的多语言数数段，直接触碰三个成年角色。桌面从左到右、手机从上到下均为 **DeepSeek、Claude、GPT**。触碰前两位只会短暂出现禁止标志；触碰 GPT 会从点击处产生放射裂纹，前景碎片震开并飞散。没有操作时，倒数结束自动揭开。
